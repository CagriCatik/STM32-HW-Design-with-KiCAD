# H

## HAL (Hardware Abstraction Layer)

ST's C library that wraps the peripheral registers in functions such as HAL_GPIO_TogglePin or HAL_TIM_PWM_Start. CubeMX generates code on top of it.

## HSE / HSI

High-Speed External oscillator (a crystal, here 8 MHz) and High-Speed Internal RC oscillator (8 MHz, about ±1 %). USB needs the accuracy of the HSE.

## Hole-to-hole Clearance

The minimum distance between the edges of two drilled holes. JLCPCB requires 0.5 mm between holes of different nets.
