# I

## I2C

Inter-Integrated Circuit. A two-wire synchronous bus supporting multiple devices, commonly used for sensors and low-speed peripherals.

## IMU (Inertial Measurement Unit)

A sensor that combines an accelerometer and a gyroscope (sometimes a magnetometer). The board uses an LSM6DS3TR-C on I²C.

## IPC-2152

The standard that relates track width, copper thickness and temperature rise to current. Example: about 0.8 mm of 1 oz outer copper carries roughly 2.8 A at 10 °C rise.

## Input Capture

A timer mode that stores the counter value when an edge arrives on a pin. Used to measure the pulse width of RC receiver signals.
