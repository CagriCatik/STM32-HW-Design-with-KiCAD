# L

## LDO (Low-Dropout Regulator)

A linear regulator that works with a small difference between input and output voltage. It is quiet and simple but turns the voltage difference into heat.

## LCSC Part Number

The order number of a part at LCSC, the distributor behind JLCPCB assembly (for example C14663 for a 100 nF 0603 capacitor). Stored as a field on every symbol.

## LQFP

Low-profile Quad Flat Package, a square package with gull-wing leads on four sides. The STM32F103C8T6 comes in LQFP-48 (7 × 7 mm, 0.5 mm pitch).
