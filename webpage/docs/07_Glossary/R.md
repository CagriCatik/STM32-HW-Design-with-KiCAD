# R

## Reverse Polarity Protection

A circuit that prevents damage when the battery is connected the wrong way round. A P-channel MOSFET in the positive line, gate to GND, does this with very little loss.

## Rotation Offset

The difference between KiCad's and the assembler's zero orientation for a package. It is corrected in the pick-and-place file and checked in the assembler's preview.

## Ratsnest

The thin lines in the PCB editor that show connections which are not routed yet.
